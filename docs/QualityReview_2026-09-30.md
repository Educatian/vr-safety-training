## 게이트 판정

- **통과: 내부 데모** (모든 영역 ≥ 2, 웹 기준).
- **다음 게이트 = 실무자 파일럿** (모든 영역 ≥ 3, 12 ≥ 4). 막는 영역: **1, 4, 5, 6, 7, 8, 9, 10, 11, 12**.
- 사람이 필요한 증거(CTA, 전문가 검토, SUS, 플레이테스트 노트)는 코드로 못 채움 → 1·10은 파일럿 전 소규모 내부 플레이테스트가 필요.

## 가장 효과 큰 수정 (우선순위: 복구 → P0 → 사람 → 환경 → 최적화)

1. **P0 캐릭터 결함**: 톱/삽을 손에 부착(손바닥 2 cm 이내 테스트), 트렌치 속 얼굴 조명 보정. → 7
2. **ECD를 데이터로**: `ecd.json`(가중치·KSA 규칙·컷·선택지 매핑) + 커버리지 매트릭스 CSV + 매핑 누락 시 실패하는 테스트. → 4, 1
3. **텔레메트리 v1 + 철회**: 스키마/빌드 버전, kind 허용목록, 학습자 ID 해시, 철회 API·보존 기간 삭제. → 5, 12
4. **크루 LLM 출력 검증 + 평가셋**: JSON 스키마·문장 수·CFR 부분집합·AI/벤더 언급 금지 검사, 실패 시 폴백, 지연/무효 로그, 40케이스 평가 스크립트. → 9
5. **정서 모델 + 접근성**: NPC별 신뢰 [-1,1] 연속값+감쇠, 숙달 기반 큐 페이딩; 모션 감소·효과음 자막·색각 안전 상태 라벨 + 시나리오 텍스트 자동 검사. → 6, 3, 10, 11
