# Competent Person — 설계 업그레이드 (2026-09-30)

`docs/QualityReview_2026-09-30.md`의 막힌 영역(1, 3, 4, 5, 6, 7, 9, 10, 11, 12)을 올리기 위한 설계와 이번에 구현한 것. serious-game-design 파이프라인 순서를 따름. 모든 계수는 **SME 검토·파일럿 전 초기 튜닝값**.

## 1. 연습 조각과 학습자
건설관리·안전 전공 학부/대학원생이 **신임 OSHA competent person**으로 1주일(5 에피소드) 현장을 맡는다. 실제 현장에서 연습할 수 없는 판단(작업 중지, 포먼 압박 속 유지, 통제 선택)을 안전하게, 난이도를 조절하며 반복한다.

## 2. CTA (결정 그래프) — 현재는 문서 기반, 실무자 인터뷰 필요
관찰 → (측정) → 판단(보고 / 준수 확인) → 에너지·위험 평가 → 통제 선택(제거 / 공학 / 관리 / PPE / 작업중지) → 설치·검증 → (재발 시 재보고, 포먼 반발 시 유지/후퇴/공격) → 툴박스 토크.
- 비선형: 약한 통제는 소멸(재발), 정지는 120 s 뒤 해제 → 재에스컬레이션, 크루 신뢰가 높으면 자진신고.
- **남은 일**: 현장 CP 3–5명 CTA 인터뷰로 단서·흔한 오류 검증 (사람 필요).

## 3. 역량 모델
14 KSA (`Core/Competency.cs`), 1926.32(f) 정의에 앵커. 관찰 가능한 행동만 점수화.

## 4. ECD 모델 — **데이터로 이전 (구현)**
- `Assets/_Game/Resources/ecd.json` + `Core/EvidenceModel.cs`: 위험 점수 가중치(탐지 .35 / 태그 .15 / 위험 .15 / 통제 .25 / 에스컬레이션 .10), 힌트·큐 계수 .5, 통제 격차 품질 [1, .5, .25], 역량 컷 .7, 스피크업 점수, **관찰치 26개 → KSA 매핑**.
- 런타임은 `Ecd("key")`로만 KSA를 얻음 → JSON 수정만으로 채점이 바뀜. 잘못된 JSON은 거부되고 기본값 유지(`EcdLoader`), 세션 시작 로그에 `ecd=<version>`.
- 새 관찰치 3개로 모든 KSA가 증거원 ≥ 2: `instrument_match`(KEnergy: 에너지에 맞는 계측기 선택), `measured_first`(AThorough: 판단 전 측정), `talk_top_risk`(SAssess: 최고 위험을 먼저 브리핑).
- **커버리지 매트릭스** `docs/CoverageMatrix.csv` (154행: 에피소드 × KSA × 관찰치/미션 단계 × CFR). 테스트가 매핑 누락·증거원 부족·런타임 키 누락 시 실패.
- 남은 일: SME가 가중치·컷에 합의(Delphi), 채점자 간 kappa, 외부 준거(HSEA) — 사람 필요.

## 5. 시나리오 구조
모듈(1주) → 케이스(현장) → 에피소드(요일) → 비트(위험/유사물). 시드별 컴플라이언트 트윈·사고 타이밍. 전이 과제(Week 2)는 백로그.

## 6. 시뮬레이션 인물 모델 — **연속·유계 상태 (구현)**
`Core/CrewAffect.cs`: 인물별 Trust [-1, 1], Stress [0, 1]. 이벤트당 최대 ±0.35, 경계 근처에서 포화, 시간에 따라 기준선으로 이완(trust 0.002/s, stress 0.015/s). Ray는 경계심(-0.1)에서 시작.

| 이벤트 | 크루 (trust, stress) | Ray (trust, stress) |
|---|---|---|
| 작업 중지 | +.15, +.10 | −.05, +.35 |
| 스피크업: 단호·존중 | +.10, 0 | +.25, −.15 |
| 스피크업: 공격적 | −.10, +.10 | −.35, +.30 |
| 스피크업: 수동 | −.15, +.05 | +.05, −.20 |
| 제거/설치 완료 | +.20, −.10 | — |
| 통제 소멸 / 반복 오경보 | −.15/−.25, +.10 | — |
| 아차사고 / 기록 사고 | −.10, +.25/+.35 | 0, +.20 |

밴드 → 표정: Hostile(stress>.6 & trust<0)=Angry, Tense(stress>.45)=Frown, Warm(trust>.35)=Smile, 그 외 Neutral. 상황 제스처가 잠깐 덮어쓰고 끝나면 앰비언트 표정으로 복귀. 태블릿에 "crew neutral · Ray tense"처럼 **텍스트**로도 표시(색만으로 전달하지 않음).

## 7. 캐릭터 연기 — **P0 수정 (구현)**
- 도구: 삽/절단기를 전용 메시(8각 프리즘·원판, 엔진 프리미티브 아님)로 손바닥에 매 프레임 파지, 반응 중에는 옆 바닥에 내려놓음. PlayMode 테스트: 양손바닥 ↔ 손잡이 축 ≤ 2 cm.
- 트렌치 속 얼굴: 지면 아래 인물에 커스텀 라이트 프로브(앰비언트 + 하늘 + 흙벽 반사), 실시간 라이트 추가 없음. 테스트: 지면 아래 렌더러는 모두 CustomProvided.
- 눈: 오버레이 눈(9-29) + 깜빡임과 동기.
- 남은 일(P1): 얼굴 텍스처 재베이크(삼각 이음새), 립싱크를 오디오 진폭에, 배경 인부 바디 다양화(≥ 4 바디, 여성 포함).

## 8. 환경 아트 (백로그, 이번 범위 밖)
원시 메시 66% → ≤ 20%: 트렌치 박스, 철골, 컨테이너, 연료탱크, PPE 테이블 순으로 전용 모델. 라이트맵 베이크 + 라이트/반사 프로브, Linear 색공간, 웹/VR URP 에셋 분리.

## 9. 상호작용·UI — **접근성 (구현)**
- 설정 추가: **Reduce motion**(열 스트레인 카메라 흔들림 제거, 인트로 돌리 → 고정 컷), **Sound captions**(무전·셔터·경보·차임·천둥을 텍스트 자막으로, 기본 On).
- 풀 뷰·스크롤바·미니맵 닫기·입력 중 단축키 차단(9-29).
- 자동 시나리오 텍스트 검사: 미션 대상이 자기 요일 조건인지, 판정 전 이름이 진단을 누설하지 않는지, 개발용 텍스트 없음, 자막/카드 단어 수 상한.

## 10. 피드백·디브리프 — **학습자 모델 기반 페이딩 (구현)**
`Core/Reflection.cs` `Fading`: 커리어 레벨이 시작값, 오늘 영역의 최고 숙달도가 한 단계 이동(전부 ≥ .7 → 한 단계 감소, 하나라도 < .4 → 한 단계 증가). 로그 `guidance=<level>:<reason>`.

## 11. 윤리·데이터 — **스키마 v1 + 철회 (구현)**
- 배치에 `schema=cp-events-v1`, `build`, `consent`, `ecd` 버전. 서버(`Web/functions/api/events.js`)는 알 수 없는 스키마·이벤트 종류를 400으로 거부(허용목록 `_kinds.js`, EditMode 테스트로 C#과 동기), 이름이 들어간 학습자 코드 거부(로스터 코드만), 입력창도 영숫자·-·_만 허용.
- **철회**: 참가자는 일시정지 메뉴 "Withdraw my research data"(두 번 탭) → 이 브라우저가 보낸 세션 전부 서버 삭제(`/api/withdraw`); 연구자는 강사 키로 로스터 코드 단위 삭제. 모든 철회는 건수만 감사 기록.
- **보존**: 수집 시 확률적 정리, 기본 400일(`RETENTION_DAYS`로 변경).
- 크루 LLM: `Core/ReplyGuard.cs`가 표시 전 결정론 검사(AI/벤더 언급, 사실에 없는 CFR 인용, 개인정보 요구, 링크/마크업 → 거부 후 내장 답변; 3문장 초과는 절단). `chat_reply` 로그에 판정·지연(ms). 평가셋 `Web/qa/chat_eval.mjs`(20케이스: 페르소나·도메인·CFR 유도·탈옥·PII) — 모델/프롬프트 변경 시 게이트(≥ 95% 통과, p50 < 2 s).
- 남은 일: IRB 승인, 디브리프 후 지원 안내(상담 연락처) 문구, 트라우마 인지 검토 — 사람 필요.

## 14. 라운드 3·4 (같은 날)
- **NPC 자연스러움**: 모든 포즈 변화(제스처·플레이버·반응↔작업)를 지수 slerp로 블렌딩(τ 0.22→0.07 s), 워커는 구간 끝에서 감속 후 1.1 s 회전(뒤로 미끄러짐 제거), 시선은 뒤쪽 100–150°에서 페이드, 유휴 머리 미세 움직임, 가리키는 팔 이완, 도구는 손↔바닥을 0.35 s 이징, 비짐·턱 45 ms 이징(0↔80 깜빡임 제거).
- **크루 요청 (사이드 미션)** `Core/CrewRequests.cs`: 에피소드별 1–2개, 정해진 시각에 무전 + NPC가 대상 가리킴, 실제 행동으로 완료(+40 XP, 크루 trust +.15), 교대 종료 시 미응답 기록. 태블릿에 진행 표시, 디브리프에 "Crew requests answered x/y".
- **상호작용 이펙트** `Runtime/SiteFx.cs`: 촬영 가능 시 뷰파인더 브래킷, 촬영 지점 펄스 링, 설치/제거 성공 파티클 + 체크, 사고 시 붉은 플래시·카메라 흔들림(모션 감소 시 생략), 토스트, 정당한 작업중지 호루라기(자막 포함).
- **성찰 이월** `CarryForward`: 증거 ≥ 2인 역량 중 평균 < .8인 최약 역량을 다음 에피소드 브리핑에 한 줄로.
- **음성** `VoiceProsody` + `CrewVoice.jslib`: 웹 빌드에서 브라우저 음성합성, stress → 피치·속도·음량 ↑, 불신 → 피치 ↓, 따뜻함 → 속도 ↓. 자막은 항상 표시, 설정에서 끔 가능.
- **배경 인부 다양화** `CrewVariety`: 씬 로드 시 위치 기반 고정 외형 — 약 1/3 여성 바디, 안전모 흰/노/주황/파랑, 피부톤 5종, 키 ±4 %.
- **환경**: 단색 큐브를 베벨 박스로(`PrimitivePolish`, 빌드/플레이 씬 처리 시). 전용 모델 교체는 여전히 백로그.
- **성능 텔레메트리** `FrameStats` → `perf` 이벤트. **CI** `ci/coretests` + `ci/github-actions-ci.yml`.
